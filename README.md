# Sinal Delas

Prototipo funcional desenvolvido para o HackaIF 2026 durante a Semana Nacional de Ciencia e Tecnologia.

O projeto utiliza visao computacional de borda com MediaPipe Hands para deteccao local e silenciosa do sinal de socorro contra violencia domestica em chamadas de video.

## Execucao

Abra o arquivo index.html em qualquer navegador moderno com suporte a WebAssembly e webcam.
